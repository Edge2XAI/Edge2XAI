Embedded ML Lessons

Learn embedded machine learning from real projects.

Short lessons on running neural networks on microcontrollers: memory, numbers, CPU time, real-time limits and the debugging that connects them. Each lesson uses a real project, with measured numbers and the failures included.

Start Lesson 1 All lessons

Who this is for

  • New engineers starting in embedded ML who want the reasons behind the terms, not only the tools.
  • Embedded engineers who already ship firmware and are adding a model to a product.
  • ML engineers who need to understand what the device does with their model.

You do not need a machine learning background for the first lessons. Each one defines its terms and ends with a short knowledge check.

Weights, Activations and Memory
